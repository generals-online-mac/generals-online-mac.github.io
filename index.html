Command & Conquer: Generals — Zero Hour, now on your Mac

A free, fan-made port that runs the classic strategy game natively on Macs with Apple chips. No Windows, no emulator: install the launcher and play the campaign, fight bots, add mods and battle other Mac players online.

Both Zero Hour and the original Generals: story missions, battles against bots and saved games.

What you need

  1. A Mac with an Apple chip — M1 or newer — and macOS 13 Ventura or later.
  2. Your own copy of the game. The easiest way is Command & Conquer: Generals — Zero Hour on Steam; the launcher downloads it for you. An old disc or a copy from a Windows PC works too.
  3. The launcher. Download it and follow the step-by-step guide — in 12 languages, with answers to common questions.

How to install

Usually 5–10 minutes. The full guide walks through every step with pictures, and the video shows the whole path from the download to the first match.

  1. Download the launcher from the latest release and unzip it.
  2. Open Terminal and type sudo xattr -cr  with a space at the end. Do not press Enter yet.
  3. Drag Generals Online.app into the Terminal window, press Enter and type your Mac password. The typing stays invisible — that is normal.
  4. Open the launcher and get the game data: sign in on the Steam tab, or point the Local Archive tab at a copy you already have.
  5. Let it patch. The launcher installs the community patch by itself — GenPatcher is not needed.
  6. Press LAUNCH and play. Mods install from the MODS section in the same window.

Why the Terminal step: the port is a volunteer project without a paid Apple certificate, so macOS blocks the first launch of a downloaded app. The command only removes that block from this one app.

Friends on Windows?

Not yet — for now Mac players play online with other Mac players. In Generals every computer calculates the whole battle on its own, and a Mac and a Windows PC round numbers very slightly differently. Within seconds the two players would be watching two different battles.

The fix is built and has been tested in hours-long Mac-and-Windows games. It is now being reviewed by the Windows community, because it touches the heart of the game. Follow the progress here, or read the longer explanation.

How it started

In early 2026 I wanted something simple: to play Generals online with friends — from my Mac. There was no Mac version, so I decided to build one. I was an app developer, not a game programmer, and the last time I had written C++ was at school.

The first month went into getting the game to draw anything at all through Metal. Then came the menus, the sound, the launcher and online play — and one complete restart from scratch along the way, once I understood which road actually leads online.

The biggest surprise came last: Macs and Windows PCs do math very slightly differently, and in a strategy game that is enough to split one battle into two. Fixing that grew into a project of its own, now shared with the whole Generals community, so that one day everyone can play together.

— okji, author of the Mac port

Questions players ask

Is it really free?

Yes. The port costs nothing and its source code is public. What you need is your own copy of the game data — for example Command & Conquer: Generals — Zero Hour on Steam.

Donations are voluntary and go toward an official Apple certificate, which would remove the Terminal step from the install.

Is the game inside the download?

No. Generals Online.app is only the client — the macOS replacement for the Windows .exe. It carries no art, sounds, videos or maps. The game data comes from your own copy.

The Steam page says "Windows only". Is buying it pointless on a Mac?

No. You are buying the game data. The Windows executable is exactly the part this port replaces with a native macOS build.

I have no Windows PC. How do I get the files onto my Mac?

You don't need one. Buy the game on Steam and use the Steam tab: the launcher signs in with your account and pulls the original files straight from Valve's servers into ~/Documents/Generals Online/.

I have an old disc copy from 2005. Will it work?

Yes — any copy you legally own works: an old install on a Windows PC, the original CD/DVD, a backup on a flash drive. Point the Local Archive tab at the folder that holds both Command and Conquer Generals and Command and Conquer Generals Zero Hour.

The launcher installs the community patch itself and removes the conflicting EA patch files, so GenPatcher is not needed. Patching rewrites files inside that folder — keep a spare copy if it is your only one.

Which Macs does it run on?

Macs with Apple chips — M1 or newer, including every MacBook Air, MacBook Pro, iMac, Mac mini and Mac Studio built on them — with macOS 13 Ventura or later. Intel Macs are not supported.

Is this Wine, CrossOver, Parallels or an emulator?

None of them. The game engine itself is rebuilt for Apple chips: graphics go straight to Metal, sound to native macOS audio, windows to native macOS windows. Nothing translates Windows code at runtime, which is why the app weighs only about 12 MB.

Why does the install need a Terminal command?

The port is made by a volunteer without a paid Apple developer certificate, so macOS blocks the first launch of the downloaded app. sudo xattr -cr removes that block from this one app and changes nothing else on your Mac.

How do I play online with other Mac players?
  • Start the game from the launcher, choose Online and sign in when the game asks.
  • The lobby list shows games hosted on a Mac by default; a game you host gets the [MAC] tag on its own.
  • Everyone in the match must run the same mod of the same version.
  • Mac players are not many at any given moment, so agree on a match in the Telegram chat or on Discord.
Can I play against friends on Windows?

Not yet. Both of you reach the same online service — you with this port, your friend with Windows Generals Online from playgenerals.online — but a Mac and a Windows PC cannot share one match yet.

The fix makes every math operation of the game give identical results on both systems: about 1,500 expressions across the game. In test builds Mac and Windows already play for hours together. It is now in review by the Windows community: pull request #2670. There is no date — it depends on the review.

Once it lands, Mac players get matches with Windows, ranked games, the ladder and tournaments.

How is it different from GeneralsX?

GeneralsX is a separate project with a different goal: one build for Linux, macOS and Windows, drawing through DXVK and MoltenVK and playing on its own server. This port is made for Macs only, writes straight to Metal, and plays on the official Generals Online servers together with the main community.

Where are my saves, maps and replays?
  • Zero Hour: ~/Command and Conquer Generals Zero Hour Data/
  • Classic Generals: ~/Command and Conquer Generals Data/
  • Custom maps and replays: the Maps/ and Replays/ folders inside the Zero Hour one
  • Installed mods: Mods/ inside the game folder
Can you just send me the game files?

No. EA released the source code of the engine — that may be built and shared, and that is what the port is. The game data was never released, so passing it around would be piracy. We don't do that and we don't link to it.
